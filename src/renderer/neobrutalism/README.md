# Retired Neobrutalism adaptations

The Carbon migration retired all Neobrutalism runtime components, copied styling
and Tailwind utilities. The former Card, Button, Dialog, Combobox, Accordion,
Bubble and navigation adaptations came from neobrutalism.dev in November 2026.
This [MIT license](LICENSE) remains as historical attribution. Current standard
controls use upstream `@carbon/react`; Code60's lifecycle adapters and native
transcript/scroll boundaries live in `../carbon`.
