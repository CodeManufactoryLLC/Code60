# Splash artwork

`stripes.jpeg` is the user-supplied Adobe Stock image `AdobeStock_2239128427.png`
(5000 × 3000), which the user has confirmed is licensed for redistribution. It is a
2560 × 1536 display copy at JPEG quality 85; the original user file is unchanged.
Code60 shows it as the splash background in Dark and System dark only, over the
solid `--bg` fallback, and omits it in Light and forced colors.

`sunset.jpeg` is the user-supplied Sunset light trails image, a 2560 × 1206
display copy of `AdobeStock_1704881164.jpeg`, resized at JPEG quality 85.
It is retained as a source asset only and is not displayed.

This directory does not grant additional rights to third-party artwork.
There is no background selector or preference.
Legacy `code60.splashBackground` values are ignored and left unchanged.
