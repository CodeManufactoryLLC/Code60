# Archived splash artwork

`sunset.jpeg` is the user-supplied Sunset light trails image, a 2560 × 1206
display copy of `AdobeStock_1704881164.jpeg`, resized at JPEG quality 85.
The original user file is unchanged. This directory does not grant additional
rights to third-party artwork.

The image is retained as a source asset only. Code60 no longer imports or displays
it. The splash uses solid Light/Dark surfaces and a D-DIN wordmark;
the subtitle stays D-DIN. There is no background selector or preference.
Legacy `code60.splashBackground` values are ignored and left unchanged.
