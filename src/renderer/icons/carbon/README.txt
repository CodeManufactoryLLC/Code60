The official exports are embedded in the HTML. Their original paths and viewBoxes are retained.
CSS masks use the same paths for checkbox and disclosure indicators.
All icon artboards render at 16 x 16 CSS pixels with currentColor.
Prompt Template uses the official 32px Carbon UI icon artboard at the standard 16px display
size. Its circles are represented as equivalent paths for the shared SVG and canvas renderer.
Overflow Menu Horizontal uses the 16px artboard with its circles represented as equivalent paths.
Database uses the official data--base 32px artboard with its circles represented as equivalent paths.
Arrow Left uses the official 16px artboard with its polygon represented as an equivalent path.
